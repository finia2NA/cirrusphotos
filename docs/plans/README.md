# Plans

This directory contains active implementation plans and current follow-up work. Current behavior is documented in [`../PROJECT.md`](../PROJECT.md) and [`../ARCHITECTURE.md`](../ARCHITECTURE.md); plans describe unfinished work and are not current-behavior sources of truth.

- `WIP_CACHING_PLAN.md` — current cache status, constraints, and longer-term direction.
- `WIP_VIDEO_PLAYBACK_PLAN.md` — implemented initial video-playback slice plus open manual acceptance and follow-up work.
- `WIP_DIFF_CACHE_PLAN.md` — broader Diff validation design. Shared infrastructure is implemented, but production proof remains disabled pending the recorded evidence gates; non-Map policies are deferred.
- `WIP_MAP_DIFF_CACHE_PLAN.md` — Map-only alternative for enabling Diff proof after the same evidence gates pass.

Completed and superseded plans are retained in [`archive/`](archive/README.md) as historical design records.
