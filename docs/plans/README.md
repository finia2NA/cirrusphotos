# Plans

Ideas, suspected bugs, and follow-up work are tracked in [GitHub issues](https://github.com/finia2NA/syno/issues). Completed and superseded plans are preserved in [closed issues](archive/README.md). Current behavior is documented in [product behavior](../PROJECT.md) and [architecture](../ARCHITECTURE.md).

The active [albums and sharing implementation plan](ALBUMS_AND_SHARING.md) records the approved sequence tracked in [#58](https://github.com/finia2NA/syno/issues/58) through [#67](https://github.com/finia2NA/syno/issues/67): normal albums first, then sharing. Each issue is a standalone implementation brief. The plan is not a current-behavior specification.
