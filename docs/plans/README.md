# Plans

This directory contains active implementation plans and current follow-up work. Current behavior is documented in [`../PROJECT.md`](../PROJECT.md) and [`../ARCHITECTURE.md`](../ARCHITECTURE.md); plans describe unfinished work and are not current-behavior sources of truth.

- `possiblebugs.md` — suspected incorrect behavior and verification notes, separate from feature ideas.
- `Ideas.md` — future feature ideas, including a unified “Prepare for Away Use” workflow and its cache-retention requirements.
- `WIP_CACHING_PLAN.md` — current cache status, constraints, and longer-term direction.
- `WIP_VIDEO_PLAYBACK_PLAN.md` — implemented initial video-playback slice plus open manual acceptance and follow-up work.
- `WIP_DIFF_CACHE_PLAN.md` — implemented unified metadata engine and stable day pages; offline verification passed, short live acceptance remains pending.

Completed, deferred, and superseded plans are retained in [`archive/`](archive/README.md) as historical design records.
