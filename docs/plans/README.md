- `PHOTO_VIEWER_PLAN.md` — completed viewer plan with a still-useful manual verification checklist.
- `CORRECTNESS_CLEANUP_PLAN.md` — completed browser, sidebar, Favorites, and timestamp correctness work.
- `REMAINING_CLEANUP.md` — remaining repository-structure cleanup.
