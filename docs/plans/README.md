# Plans

This directory contains implementation plans, completed design records, and current follow-up work. Current behavior is documented in [`../ARCHITECTURE.md`](../ARCHITECTURE.md) and the root `AGENTS.md`; completed plans may describe earlier states and are not implementation sources of truth.

- `CACHING_PLAN.md` — current cache status, constraints, and longer-term direction.
- `PHOTO_VIEWER_PLAN.md` — completed viewer plan with a still-useful manual verification checklist.
- `CORRECTNESS_CLEANUP_PLAN.md` — completed browser, sidebar, Favorites, and timestamp correctness work.
- `LIBRARY_BROWSER_PLAN.md` — historical staged browser implementation plan.
- `UI_PLAN.md` — historical shell and appearance plan.
- `REMAINING_CLEANUP.md` — cleanup findings intentionally left for a later decision.
