Install

Cirrus Photos is signed but not notarized, because there is no paid Apple Developer account behind it. macOS therefore blocks the first launch until you allow it once.

Steps

  1. Download the latest release from the releases page and open it.
  2. Drag Cirrus Photos to the Applications folder.
  3. Open it from Applications. macOS says the app could not be verified. Close that message.
  4. Open System Settings, go to Privacy & Security and scroll to the Security section.
  5. Click Open Anyway next to the message about Cirrus Photos, then confirm and authenticate.

This is needed only once. Control-click and Open no longer gets past the block on current macOS.

Terminal alternative

Remove the quarantine flag instead of using System Settings:

xattr -dr com.apple.quarantine "/Applications/Cirrus Photos.app"

Sign in

On first launch the app asks for your server address, username and password, and a six-digit code if the account uses two-factor authentication. A bare host name means https://host:5001. HTTP is not accepted.

Updates

Updates arrive through the app's built-in updater.

Uninstall

  1. Quit the app and move Cirrus Photos from Applications to the Trash.
  2. Delete the folder ~/Library/Application Support/de.richardhanss.cirrus-photos.

Saved accounts are stored in the Keychain. Use Sign Out in the app before uninstalling, or remove the entries in Keychain Access.
